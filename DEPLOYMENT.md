# Abhishek Bade Portfolio — Deployment Package

This package contains the updated Vite/React source and the production build in `dist/`.

## Deploy the production site

Upload the contents of `dist/` to a static hosting service such as Netlify, Cloudflare Pages, or GitHub Pages.

## Build from source

Install Node.js, then run:

```sh
npm install
npm run build
```

The production site will be generated in `dist/`.

For Vercel or Netlify Git-based deployment, use the repository root as the project directory, `npm run build` as the build command, and `dist` as the output directory.
